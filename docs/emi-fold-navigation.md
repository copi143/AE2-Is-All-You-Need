# EMI 分类导航

索引侧边栏现在使用完整索引上的分类树。标题区包含大类过滤按钮、返回与分类路径，下面仍使用 EMI 原生网格和分页。

## 操作

- 第一行：**全 / 方 / 物 / 液 / 他**，分别对应全部、方块、物品、流体、自定义资源。悬停可见完整名称与当前搜索结果中的匹配数量。
- **Alt＋左键或右键**点击分类槽：小组在原位置展开，大组进入下一层。不会作用于背包、配方、收藏或历史中的普通物品。
- **Alt＋点击任一内联成员**：收起该组。内联成员共享组底色和合并边框，普通点击仍按单个物品处理。
- 第二行的 `<`：返回上一浏览位置并恢复页码；`«`：返回所选大类的根目录。
- 点击可见路径段可以跳到该层；较长路径通过悬停查看。
- 普通物品沿用 EMI 的配方、用途、收藏、拖拽行为。分组继承 EMI 的多选材料类型，普通点击进入其材料选择界面。
- 较大分组的角标用 `k` 缩写并限制在槽内；Tooltip 显示精确成员数、完整分类路径与最多 24 个预览图标。

## 搜索和阈值

EMI 仍负责全部搜索语法（名称、模组、标签、Tooltip、正则、组合等）。分类代码只读取其已匹配的原始条目，不将分组加入 EMI 搜索索引。

每个分类根据**当前匹配成员数**投影：

| 匹配数量 | 显示方式 |
| --- | --- |
| 0 | 隐藏 |
| 1～3 | 直接显示原始物品/流体条目 |
| 4～19 | 显示层压平为一个叶组，可在原位置内联展开 |
| ≥20 | 保留子分类，通过钻入浏览 |

大类过滤与搜索取交集。所有大类按钮的数量显示当前搜索在各大类中的条目数，方便切换。分类归属始终由完整索引确定，搜索不会重新把成员分配给其他家族。

输入新查询时暂时从当前大类根目录浏览匹配结果；查询中的钻入与普通浏览独立。清空查询后恢复原来的分类位置、页码和手动展开/收起状态。等待 EMI 异步发布新结果时，暂时保留上一轮匹配集合，但仍按新的页容量重排，避免窗口缩小时沿用超出一页的自动展开结果。

仅 EMI 配置为搜索目标的侧边栏使用搜索结果；其他索引侧边栏继续遵循 EMI 原本的搜索范围配置。

## 小组压平与自动内联

统一以当前匹配总数 **小于 20** 作为小类界限。例如内部为 `4+1+1+4+1` 的分类，总数 11，显示为一个含 11 个成员的叶组；展开时直接列出 11 个成员，不再显示二级分类。分类树本身保持完整。只有一个子家族的链仍会压缩到有描述意义的名称，全部/资源类型等结构节点不会合并不相关分类。

自动展开的容量预算使用 EMI 网格的实际 `pageSize`（已扣除导航区及排除区域）：

1. 先应用用户明确要求的展开/收起状态。
2. 当前显示槽数严格少于一页时，优先尝试较小的叶组；相同大小保持源顺序。
3. 展开 N 个成员需要新增 N−1 个格子，只有剩余格子足够时才自动展开。未分类的外部条目也计入占用。
4. 展开后的成员留在原分组的位置，顺序不变。

**自动展开不会使原本一页的结果溢出；手动展开允许翻页。** 手动收起的组不会被自动规则立即打开。手动状态按侧边栏、导航层及搜索状态隔离，返回时恢复；切换大类或重建分类树时清理。

窗口大小或 GUI 比例变化时重新计算自动展开。匹配数量不足 4 时仍直接显示原始条目，优先于手动收起状态；达到 20 后不再内联，恢复层级浏览。

## 布局与生命周期

导航区从原物品网格预留两行，不覆盖容器或原来的翻页按钮。主索引侧边栏至少需要三列、三行，并且导航区域不能与 EMI 排除区域重叠；不足空间时回退为原始列表，避免产生无法返回的分组。INDEX 子面板保持原始列表。

运行时只在客户端主线程提取 ID、类、标签和 NBT 引用等轻量快照，分类计算在后台进行。完整索引更换时重新建立树；旧任务不会覆盖新索引。分类未就绪时显示原始索引，导航按钮暂时不可用。

分组收藏保存稳定组键和成员快照。树可用时按同一节点恢复；EMI 重载期间或旧键失效时保留快照。内联成员的收藏按单个成员保存，恢复为原始物品，不持久化临时展开状态；同时兼容旧版本展开成员记录。

## 验证

- common、Forge、Fabric 的 Kotlin/Java 离线编译通过。
- 英文/简体中文资源生成通过。
- 45 项相关测试通过，包含搜索 4→3→0 的显示切换、搜索与大类交集、单子链导航、返回及页码恢复、空结果、NBT 引用层级、旧聚类迁移规则和渲染辅助逻辑。
- 新增 9 项内联规则测试，覆盖 `4+1+1+4+1` 压平、19/20 边界、外部槽位占用、手动收起、页容量变化及状态隔离。其中遍历了 9,984 组大小/容量组合，验证自动展开不超页且成员完整有序。
- 用本地 19,272 条多模组样本比较 Kotlin 与 Python 的家族结果，全部一致；四个大类的投影成员完整且不重复。
- 使用 EMI 1.1.24+1.20.1 的真实 jar 检查布局 NEW 重定向捕获参数、鼠标入口、标题背景和分页相关注入点签名。

可选大样本测试通过环境变量指定临时夹具 `AE2INYA_FOLD_FIXTURE`，真实 jar 契约检查通过 `AE2INYA_EMI_JAR` 指定 jar 路径；未提供时这两项测试会跳过。其余纯逻辑测试不依赖本地样本或启动 Minecraft。
