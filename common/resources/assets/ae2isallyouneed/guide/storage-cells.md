# 大容量存储元件

面向整合包末期的存储元件家族：容量单位跨越 K → M → G → T 全部 SI 词头（1K 至 256T 共 20 个档位），并移除了原版的显示数量上限——堆叠计数不再被 UI 截断。

## 物品存储元件

从 1K 到 256T 的完整档位序列，基于 long 的容量计算，行为与原版 `item_storage_cell` 一致：放入 ME 驱动器即可扩容，元件上的 LED 指示剩余空间。

<ItemLink id="creative_me_cell" />
