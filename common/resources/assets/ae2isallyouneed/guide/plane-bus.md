# ME 破坏/成型面板专用线缆

智能线缆外观的特殊线缆，把相邻的破坏面板与成型面板组织成一个多方块结构，**整个结构只消耗 1 个频道**，而不是每块面板各付一个。

<ItemLink id="plane_bus" />

## 组网规则

- 线缆之间：相同方块或六向相邻即链式互联。
- 面板与线缆：只有装在**同一个宿主方块**上的面板才属于该结构；隔壁线缆宿主上的面板属于别的结构。
- 规模上限：单结构最多 **32 条线缆 + 64 块面板**（破坏与成型合计）。
- 悬停任意成员可查看当前集群的统计（Jade / WTHIT / TOP）。

## 成型与否

- 满足规模上限 → 结构**成型**：BFS 寻路中首个拿到频道的成员让全体零成本搭车（与合成 CPU 同机制），共享线缆的频道瓶颈不会被集群内部占用。
- 超出上限 → 结构**未成型**：所有成员被剥夺频道，整个结构与网络断开。

## 配色

固定为透明色（可与任意颜色线缆互联），目前不支持染色。
